

## 1️⃣ Создание записи

**Админ пишет в группе:**

```
/queue ООП 12.12.2025 14:30

# ООП - название предмета
# 12.12.2025 - дата занятия
# 14:30 - время начала занятия
```

**Бот публикует сообщение в группе:**

```
📘 Запись на ООП
📅 12.12.2025
⏰ 14:30

[ ✅ Участвую ]
```

### Кнопка `[ ✅ Участвую ]`

- Inline-кнопка, видна всем, привязана к сообщению
- При нажатии прилетает `callback_query` боту
- Студент получает уведомление:

  - первый раз: `"Вы записаны ✅"`
  - повторно: `"Вы уже участвуете ℹ"`

## 2️⃣ Формирование очереди

- Через 24 часа после отправки (или за 2 часа до пары) бот редактирует сообщение:

```
📘 Очередь на ООП
📅 12.12.2025

1. @user1 (или ФИО)
2. @user2
3. @user3
```

- Кнопка `[ ✅ Участвую ]` исчезает (`reply_markup=None`)

## 3️⃣ Отметка последнего сдавшего

- Когда занятие начинается, бот **добавляет новое сообщение или редактирует очередь**, добавляя кнопку:

```
[ Я последний ✅ ]
```

- Студент, который подошёл **последним** к преподавателю, нажимает кнопку
- Бот фиксирует:

  - всех, кто сдал **до последнего** → `attempts_count += 1`
  - всех, кто **после последнего** → попытка не засчитывается

- Сообщение с кнопкой редактируется, кнопка исчезает (`reply_markup=None`)

---

## 4️⃣ Напоминание, если никто не нажал кнопку

- Через 5 часов после начала занятия бот проверяет, был ли отмечен последний сдающий
- Если **никто не нажал кнопку**, бот отправляет в группу уведомление:

```
⚠ Последний студент, который сдавал ООП, отметься!
```
