## 2. Обработчики команд

### **Студенты**

- [ ] `/join` / Кнопка `[✅ Участвую]` → записаться в очередь
- [ ] `/leave` → выйти из очереди

### **Админ**

- [ ] `/newlab <предмет дата время>` → создать новую очередь
- [ ] `/close <предмет дата время>` → закрыть запись досрочно
- [ ] `/shuffle <предмет дата время>` → полностью перемешиваем участников
- [ ] `/setadmin @username` → добавить/убрать админа
- [ ] `/set_last @user_id <предмет дата время>` → указать вручную последнего сдавшего
- [ ] `/set_first @user_id <предмет дата время>` → поставить человека в начало очереди
- [ ] `/set_FIO @user_id <Имя> <Фамилия>` → чтобы отображать ФИО, а не ник в ТГ. Задаётся один раз
- [ ] `/set_group @user_id @user_id ... @user_id` → "создать компашку", чтобы бот старался их вместе ставить
